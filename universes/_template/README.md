# Universe template

Skeleton copied by `world-init`. Prefer `sb new-universe <id> --name "..."` — it writes a valid
manifest and store directory for you.

- `universe.json` — manifest: premise, hard rules, voice. Read into every brief.
- `store/` — canon. One JSON file per container. See [store/README.md](store/README.md).
- `narrative/` — outlines, drafts, and published text. The only free-form part.
- `notes/` — scratch. Ideas live here until they are recorded as canon.

Format spec: [../../docs/data-model.md](../../docs/data-model.md)
